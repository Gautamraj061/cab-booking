# Cab Booking Project (Ready Setup)

## Steps to Run

1. Install dependencies:
npm install

2. Setup Supabase:
- Create project at https://supabase.com
- Copy URL & ANON KEY
- Paste into .env.local

3. Run locally:
npm run dev

4. Deploy:
- Push to GitHub
- Import in Vercel
- Add env variables

Project is ready 🚀
